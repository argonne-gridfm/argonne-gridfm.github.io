The Project

Intelligent AI for a Resilient Power Grid

GridAI brings modern machine learning to the hardest problems in power system operations. The project is organized around two complementary product lines: LUMINA, a family of graph-based foundation models, and GridMind, an agentic framework that reasons about grid risk and operations.

LUMINA

A Grid Foundation Model that Transfers

LUMINA is a multi-task, multi-dataset foundation model for power grid applications. Its defining strength is generalization: a single graph-based model that transfers across grid topologies, scales, and tasks — moving beyond one-model-per-grid. AC Optimal Power Flow (ACOPF) is our current primary focus, with the framework designed to extend to a broader family of grid optimization and analysis tasks.

  • Topology-transferable — generalizes to unseen power networks without retraining
  • Multi-task & multi-dataset — one backbone across tasks and grid scales (14 → 13,659 bus)
  • Heterogeneous graph transformer over power-network structure
  • Physics-informed objectives for constraint feasibility
  • ACOPF today, extensible to the broader grid optimization & analysis family
  • LUMINA-Bench — open benchmark for ACOPF surrogate learning

GridMind

Agentic Workflows for Grid Operations

GridMind is an LLM-powered, LangGraph-based agentic framework. An orchestrator routes tasks to specialized agents that perform power system analysis, contingency and cascading-failure reasoning, and weather-driven risk assessment — calling neural solvers like LUMINA when needed.

  • LLM orchestrator routing to deterministic, specialized executors
  • Weather-driven power grid risk assessment
  • Power system analysis & operations support
  • Interactive interface with reproducible, content-addressed artifacts
